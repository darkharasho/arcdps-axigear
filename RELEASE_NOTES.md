# Release Notes

Version v0.2.2 — October 10, 2026

## New

- Problems that don't matter to you can now be dismissed. Click the x
  at the start of a row in the checklist and that check stops counting
  for the current comp, including on the badge. "N dismissed" at the
  bottom of the list shows them and lets you restore any of them.
- The badge can be hidden: untick "Show badge" in axigear's options.
  The checklist still opens with the hotkey or from arcdps's window
  list.

## Fixes

- Spears no longer fail the weapons check as "harpoon". The GW2 API
  still uses the old underwater names for spears and harpoon guns.
